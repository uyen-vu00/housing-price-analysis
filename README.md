# Housing Price Analysis

## Project Overview

This project explores the relationship between residential property characteristics and housing sale prices.

The analysis focuses on identifying features associated with housing prices and investigating how these relationships differ across property characteristics and market segments.

## Research Question

Which property characteristics are most strongly associated with housing prices, and how do these relationships vary across different segments of the housing market?

## Objectives

- Understand the structure and quality of the housing dataset.
- Identify important numerical and categorical features.
- Explore relationships between property characteristics and sale prices.

## Dataset

This project uses the Ames Housing dataset, downloaded from Kaggle.

- **Source:** [Kaggle – Ames Housing](https://www.kaggle.com/datasets/shashanknecrothapa/ames-housing-dataset?select=AmesHousing.csv)
- **File:** `train.csv`
- **Target variable:** `SalePrice`

The original dataset is not included in this repository.

The dataset will be used for educational and exploratory analysis.

## Methodology

1. Data loading and initial inspection
2. Data quality assessment
3. Exploratory data analysis
4. Feature relationship analysis
5. Price comparison across selected property groups
6. Summary of findings and limitations

## Project Status

In progress.

## Limitations

This project is an exploratory analysis of historical housing sales in Ames, Iowa. The observed relationships do not necessarily imply causation and should not be directly generalized to other housing markets.
